# SAND RESCUE Project Status

This repository was empty when development began. It now contains a Unity 6 project scaffold with the Step 1 vehicle foundation and Step 2 mission/gameplay systems imported into `Assets/SandRescue`.

## Current status

- Unity project scaffold: created
- Step 1 vehicle foundation: imported from the starter package
- Step 2 gameplay source: imported
- Starter mission asset creator: imported
- Unity Editor compilation: requires Unity 6 Editor
- Play Mode and device testing: not yet performed
- Remote GitHub push: pending repository authentication

Open the project in Unity 6000.0.43f1, allow Package Manager to resolve packages, then run `Tools → SAND RESCUE → Create Step 2 Starter Missions`.
